# katla - custom edushit client for iOS
this project was entirely vibe coded by Gemini 3.1 Pro.

## features

- 🌙 dark/light mode with customizable accent color
- 📱 liquid ass
- ✨ animations and interactive elements
- 📊 display of schedule, grades, attendance and homework
- 🚀 easy login (4 methods to login)

## technology

- swift

## installation and startup

1. clone repo
2. compile in xcode
3. deploy on your device
